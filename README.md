# bookbot

BookBot is my first [Boot.dev](https://www.boot.dev) project!

BookBot reads a text file, counts its words and reports how often each letter appears, from most to least frequent. 

Run the program using any readable text file. 
Run command `python main.py <bookpath>` in the CLI 

Provided Test files include:
 - frankenstein.txt
 - mobydick.txt
 - prideandprejudice.txt
  Edge Cases:
  - emptyfile.txt
  - numbers.txt
  - oneword.txt

The project also contains my Project Notebook including: IPO table, Flow diagram, Design decisions and justifications, Test Cases and Reflection on Challenges and Solutions
